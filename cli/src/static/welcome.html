Welcome to Rango

Your Rust web framework is up and running. Start building your application by editing the files below.

$ cargo run

What Rango gives you

Fast routing
Declarative URL patterns via urls! macro, inspired by Django.
Template engine
Jinja-like templates with {{ "{% block %}" }} inheritance in templates/.
Static files
Drop assets in static/ — served automatically at /static.
Migrations
Database migration files live in migrations/, ready for SQLx.

Next steps

1
Edit your routes
Open src/urls.rs and declare your URL patterns using urls!.
2
Create your views
Add handler functions annotated with #[view] and wire them to routes.
3
Configure your environment
Copy .env.example to .env and set your DATABASE_URL and other variables.
4
Run migrations
Use rango migrate once your models are defined to apply schema changes.
